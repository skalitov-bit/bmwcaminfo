BMWCamInfo для BMW MGU: гибридная база MapCam + еСтрелка по России и обновлённые предупреждения HUD/KOMBI.

Изменения относительно опубликованной 0.9.1:
- Компактная бинарная база: 313 682 записи, из них 151 230 участвуют в предупреждениях о камерах и весовом контроле. Каталог занимает около 10,88 МиБ. База входит в установочный пакет и читается географическими блоками.
- При объединении данных применён приоритет еСтрелки для совпавших объектов. Сохранены доступные названия комплексов.
- На HUD/KOMBI сверху отображается вид контроля (скорость, стоп-линия, красный свет и другие категории), ниже — модель, если она есть в базе. Текст заглавными буквами.
- При превышении строго более чем на 20 км/ч вокруг знака ограничения мигает внешнее красное кольцо: 0,5 секунды включено, 0,5 секунды выключено. На участке средней скорости учитывается средняя скорость. Для муляжей и при неизвестных данных мигание не включается.
- Новый сглаженный контурный значок камеры. Все красные элементы HUD/KOMBI используют оттенок ободка знака ограничения #D32C36.

Установка: скачайте aurelm_speed_camera_warning@0.9.7.mgu и установите привычным способом через менеджер приложений MGU. TGZ — альтернативный пакет. Копировать SQLite отдельно не нужно.

Исходники этой сборки находятся в приложенном BMWCamInfo_0.9.7_Source.zip и в репозитории под тегом релиза. Сборка GitHub Actions сверяет каждый файл MGU и TGZ с локально проверенной сборкой, затем повторно запускает тесты готового пакета.

Проверки файлов внутри MGU: запуск приложения и 7 перерисовок; реальные записи скорости, стоп-линии и красного света; раздельные строки типа и модели; строгий порог +20 и дробная скорость; средняя скорость; две поверхности вывода; фазы мигания; остановка таймеров; отсутствие повторной передачи всей карточки при каждом мигании. TEST-RESULTS.json и контрольные суммы приложены.

На реальном MGU эта сборка ещё не испытана. GIF показывает отрисовку кодом приложения для примера: лимит 60, скорость 90 км/ч, расстояние 500 м.

Гибридная база в этой версии обновляется вместе с пакетом приложения. Новый успешный запрос к API MapCam в рамках выпуска не выполнялся и не заявляется. Windows EXE загрузчик этим релизом не изменяется.
