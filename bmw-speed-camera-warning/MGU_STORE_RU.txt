SpeedCAM **0.9.104 gps test version** · звуковой сервис **0.1.52**.

### Изменения относительно 0.9.103
- В настройках под SET LANGUAGE добавлена кнопка «Поддержать проект» с цветным значком пончика.
- В отдельном окне — два QR-кода: CloudTips для оплаты из РФ и Buy Me a Coffee для оплаты из других стран.
- Добавлен контакт Telegram: **skalitov** для запроса карт регионов и пожеланий. Текст отцентрирован; окно переведено на английский.
- Окно открывается и закрывается касанием и джойстиком. Поддержка добровольная; приложение и база распространяются бесплатно.

Проверены готовый пакет, запуск с GPU и резервным PNG, переключение языка, диалоги языка/HDD и оба QR-кода. Проверка на реальном MGU для этой сборки не выполнялась.

**Установка:** обновите источник `skalitov-bit/bmwcaminfo` в MGU Store. Звуковой сервис **0.1.52** сохранён без изменений. Графические зависимости — из `cauliflowermossgrape/idrive7-apps`.
