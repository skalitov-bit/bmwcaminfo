SpeedCAM — установка из MGU Store

В магазине на MGU откройте Settings / Настройки → Add source / Добавить источник.
Репозиторий: skalitov-bit/bmwcaminfo. Канал: Releases / Релизы.
Если источник уже добавлен, повторно добавлять его не нужно.
Нажмите Check now / Проверить обновления. Выберите SpeedCAM → Установить
(или Обновить, если приложение уже установлено).

Магазин скачает и установит нужную версию звукового сервиса, затем приложение.
Звуковой сервис отдельно выбирать и устанавливать не требуется. Он может
отображаться в списке компонентов магазина — это нормальная зависимость.
Если магазин показывает Restart pending, перезапустите MGU штатным способом
после завершения установки. Не прерывайте питание во время установки.

Для онлайн-установки нужен работающий интернет у магазина. При ошибке загрузки
или установки зависимости приложение не должно устанавливаться без неё.
Если MGU Deploy старее требуемой версии, магазин сначала обновит его из своего
встроенного источника. Используйте актуальные MGU Store и mgu-updater.

Для офлайн-установки скопируйте папку mgu-repo из подготовленного USB-комплекта
в корень флешки. Откройте магазин и выберите SpeedCAM из источника флешки.
Оба пакета уже в комплекте. Требуемые системные компоненты магазина должны
быть заранее установлены; флешка не содержит обновление самого MGU Store.

Простая установка одного файла .mgu вне магазина не устанавливает зависимость.
ZIP-комплект сам по себе также не является установочным форматом магазина.

Для автора релиза
1. Собрать приложение и native/bmwcaminfo-voice через tools/pack_voice.py.
2. Запустить tools/build_store_catalog.py --artifacts <релиз> --out <каталог>.
3. Опубликовать TGZ приложения и сервиса в релизе приложения.
4. Проверить доступность файлов, их размер и SHA-256.
5. Последним опубликовать catalog.json и SpeedCAM.png в релизе с тегом catalog.
   Этот служебный релиз не помечать Latest. Каталог использует схему 2 и requires.
6. При каждом новом релизе обновлять каталог: при его наличии магазин читает
   именно его, а не самостоятельно ищет новые версии во всех релизах.

Поддерживаемая платформа: BMW MGU ID7. Установка на реальном MGU и фактическое
воспроизведение звука требуют отдельной проверки в автомобиле. Автоматическая
установка компонента сама по себе не доказывает устранение отсутствия звука.

Формат проверен по MGU Store, коммит 407f13e2091a028f7855568c51ba36f10dfab40d:
