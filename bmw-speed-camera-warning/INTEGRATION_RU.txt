BMWCamInfo 0.9.0 — оболочка BMW и совместимость с данными MapCam

РЕЗУЛЬТАТ
Сохранены карта, вкладки, локальные камеры и выбор KOMBI/HUD.
Предупреждения MapCam теперь работают по секторам и геометрии самой базы,
без прежнего ограничения на 307 дорожных привязок Марий Эл.
В базе: 84 594 камеры России, включая 439 в Марий Эл и 118 в Йошкар-Оле.
18 817 записей имеют геометрию контроля, всего 41 200 точек.
Это участки разных типов, не только измерения средней скорости.

Источник: BMW MapCam.zip из пользовательского форка skalitov-bit/bmwcaminfo.
Исходный коммит: ae643a4a9052a79cf3169696be2df3fa8db4d15f.
Ревизия базы: 11.11.2026 14:25:39 UTC (17:25:39 Москва).
SQLite SHA256: 47c28247eb472046a4c1628d318826fc15c1adf37d7fe61529e23a86e16ac0c8.
Учётные данные MapCam в приложение и архив исходников не включены.

КАК РАБОТАЕТ
Точки: сектор, направление и расстояние из записи, внешний предел 2000 м.
Если расстояние в записи равно 0, применяется только внешний предел.
Участки: движение по направлению пути с допуском 20 градусов и боковым
отклонением до 70 м. Отображается расстояние до конца. На участках от 300 м
рассчитывается средняя скорость. Близкие параллельные дороги при таких
допусках не всегда различимы — это не полноценная привязка к дорожному графу.
Для нового предупреждения нужны две последовательные свежие координаты,
скорость больше 15 км/ч и точность GPS строго лучше 15 м.
Потеря GPS, давность более 3 секунд или скачок координат сбрасывают контроль.
При подключении посреди участка средняя считается с подключения и помечается
как частичная. Время остановок учитывается.
Голос одной камеры повторяется не чаще раза в 20 минут до перезапуска приложения.
Очередь ограничена, устаревшие голосовые запросы отменяются.
Неизвестный лимит не заменяется выдуманным значением. Направленная точечная
камера без азимута пропускается; в текущей базе 122 записи без такого азимута.
Пользовательские камеры сохраняют прежнюю работу по записанной траектории.

НАСТРОЙКИ
Откройте «Настройки» и нажмите 3 — MapCam.
1/2 выбирают строку, 4 изменяет значение, 3 возвращает KOMBI/HUD.
Доступно и сенсорное нажатие строки.
Голос: каждая камера / при превышении / выключен.
Порог: лимит камеры / +10 / +18 / +20 км/ч.
Дистанция: из базы / 500 / 700 / 1000 / 2000 м.
Порог относится к предупреждению, а не к разрешённой скорости движения.

ГОЛОС И ДИСПЛЕИ
Нужны ранее установленные bmwcaminfo-voice и cluster-render.
Используется общая фраза «Внимание, впереди камера» (camera-500.m4a;
имя файла историческое, дистанция в этой фразе не произносится).
KOMBI/HUD: CONTROL — участок, AVG — средняя, PART AVG — частичная средняя.

ГРАНИЦЫ СОВМЕСТИМОСТИ
Это самостоятельное ядро по проверенным правилам APK, а не полный клон.
Серии зуммера, отдельный голос каждого типа и фраза завершения ещё не перенесены.
В текущем SQLite отсутствуют часы работы и признак контроля после камеры.
Они сохранены как неизвестные и не угадываются. Для этой базы фильтр часов
не включён, продление контроля после камеры не применяется.
Импортёр и ядро принимают дополнительные control_direction, hour_start/hour_end,
если последующая версия экспортёра будет их предоставлять.
Другие служебные флаги/рейтинги APK пока не воспроизведены.
В список камер не добавлялись лежачие полицейские и другие дорожные опасности.

ПРОВЕРКА
Пройдены автоматические GPS-сценарии направлений, секторов, дистанций,
порогов, потери/скачков GPS, проезда камеры, завершения участка, средней
скорости, остановок, подключения посреди участка и повторов голоса.
Проверены реальные записи вне Марий Эл, индекс участков, защита кэша,
запуск приложения, настройки и очередь голоса. Отчёт: TEST-RESULTS.txt.
Интерфейс 0.9.0 установлен в MGU Emulator http://127.0.0.1:8077/.
Эмулятор не предоставляет автомобильный SatellitePositioning SDK.
Его сообщение об отсутствии GPS не является проверкой GPS автомобиля.
Синтетические GPS-треки исполняются тестами; реальная поездка, голос,
KOMBI/HUD и нагрузка непосредственно в BMW не проверялись.
Новая загрузка API MapCam не состоялась: сохранённая учётная запись оказалась
недоступна для чтения. Использована прежняя выгрузка. Успешный ответ API
MapCam в этой доработке не заявляется.

УСТАНОВКА И ОБНОВЛЕНИЕ
TGZ — пакет MGU Store; MGU — формат установочного инструмента проекта.
Устанавливайте 0.9.0 тем же способом, что прежний BMWCamInfo.
Windows EXE Updater остаётся отдельным загрузчиком базы, его EXE не изменён.
Для отката сохранён комплект 0.8.0. Локальный user-cameras.json не удаляется.
Кнопка обновления обращается к JSON в форке skalitov-bit/bmwcaminfo.
Релиз 0.9.0 использует mapcam-rus-v2. Старая удалённая база mapcam-rus-v1
будет отклонена с сохранением встроенной mapcam-rus-v2.
Для новой выгрузки сейчас импортируйте её и пересоберите пакет.

ПОВТОРНАЯ СБОРКА ИЗ КОРНЯ ИСХОДНИКОВ
1. Выгрузите базу Windows Updater, упакуйте current.json и releases в ZIP.
   Также принимается ZIP с одной SQLite и manifest.json.
2. python bmw-speed-camera-warning/tools/import_mapcam.py "BMW MapCam.zip"
3. python bmw-speed-camera-warning/tools/build_local.py --out release-local
Дорожные привязки OSM для предупреждений пересоздавать не требуется.
Первая сборка получает закреплённые SHA256 зависимости; далее использует кэш.
