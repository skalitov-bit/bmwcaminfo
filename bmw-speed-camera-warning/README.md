# SpeedCAM 0.9.32

Уведомления о камерах из гибридной базы MapCam + еСтрелка и пользовательских точек.

- Приоритет HUD/KOMBI: класс alert, уровень 1000, нижние слои cluster-render временно скрываются.
- Без 20-минутной блокировки: объявления учитываются по отдельным проездам.
- Общие настройки голоса, дистанции и превышения для всех источников.
- Согласованный выбор камеры на Радаре, HUD, приборке и в голосе.
- Настраиваемый повтор за 200 м, проверка результата звукового запроса.
- Проверка направления и бокового смещения; явная индикация качества GPS.

Инструкция и ограничения: [INTEGRATION_RU.txt](INTEGRATION_RU.txt).
Формат базы: [BINARY_FORMAT.txt](BINARY_FORMAT.txt).
Источники данных: [DATA-NOTICE.txt](DATA-NOTICE.txt).

Фоновое окно и автозапуск после сна MGU требуют испытаний на автомобиле.
