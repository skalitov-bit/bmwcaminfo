База SpeedCAM

В приложении используется компактный бинарный каталог hybrid-blocks-v1,
подготовленный из предоставленных пользователем исходных данных.
При объединении совпадающих координат применяется заданный приоритет источников.
Названия моделей берутся из исходного справочника; отсутствующие модели не выдумываются.
Муляжи отмечены явно. Для предупреждений используются камеры, мобильные точки,
муляжи и весовой контроль. Дорожные опасности сохраняются в каталоге отдельно.

Чтение выполняется по географическим блокам с ограниченным кэшем.
Обновления публикуются в speedcam-db; встроенная база служит резервной.
Дата на карте обозначает поколение установленной базы.
При наличии геометрии поддерживается контроль средней скорости на участке.
Без геометрии соответствующая запись остаётся точечным предупреждением.
Реализация не утверждает полного воспроизведения алгоритмов сторонних приложений.

Права на исходные базы сохраняются за их правообладателями.
Данные не становятся частью MIT-лицензии программного кода.
Этот пакет не подтверждает разрешение правообладателей на распространение данных.
