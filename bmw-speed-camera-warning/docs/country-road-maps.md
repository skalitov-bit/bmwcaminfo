# Карты целых стран

Добавлена поддержка единой карты «Республика Беларусь». Это изменение исходного кода; опубликованная версия 0.9.96 не меняется и этот пакет не поддерживает.

Формат SCROAD01 и сетка 0,01° сохранены. Максимальный индекс увеличен с 2 до 8 МиБ и с 50 000 до 200 000 ячеек. Ограничения отдельного файла (64 МиБ), дорожного блока (1 МиБ), числа видимых ячеек (320) и кэша декодированных данных (12 МиБ) сохранены. Индекс загружается при открытии карты, геометрия — только для текущей области экрана.

## Совместимость каталога

`maps/catalog.json` сохраняет `schema: 1`. Обычные пакеты остаются в `cities`. Пакеты с индексом более 2 МиБ или 50 000 ячеек помещаются в дополнительный массив `extendedCities`.

Старое приложение читает только `cities`, поэтому ему не предлагается несовместимый файл. Новый читатель проверяет оба массива, отклоняет повторяющиеся идентификаторы и объединяет записи для меню. Локальный кэш каталога содержит нормализованный общий список. Генератор автоматически выбирает нужный массив по фактическому размеру индекса. При публикации сохраняйте оба массива и все остальные карты.

## Беларусь

Полная выгрузка [Geofabrik Belarus](https://download.geofabrik.de/europe/belarus.html) от 23 ноября 2026, 21:21:17 UTC. Данные © OpenStreetMap contributors, ODbL 1.0. Дорожные классы и упрощение геометрии соответствуют существующим картам; пешеходные тропы и здания в этот формат не входят. Прямоугольник охвата может включать продолжения дорог за границей.

Пакет: 32 436 959 байт, индекс 4 492 347 байт / 139 359 ячеек, 554 838 исходных дорожных линий, 854 469 фрагментов. SHA-256: `20b5fdd7cdf705d099231f5c47e2cc13b19f7a16953ba84a85896f4100a5fe80`.

Проверены все блоки пакета, Минск, шесть областных центров, Пинск, Браслав и Мозырь. Проверены установка, повторное открытие, удаление, сохранение базы камер, сортировка от Москвы и совместимость прежних карт. Тесты выполнялись на Windows / Node.js 8.17.0; проверка на реальном MGU ещё не проводилась.

Отдельный запуск измерения в Node.js 8: индекс Беларуси добавляет около 23,9 МиБ к heap, область Минска радиусом 2,5 км — ещё 2,6 МиБ. Для сравнения индекс Москвы с областью — около 9,0 МиБ. Это замеры на компьютере, а не обещание расхода памяти на MGU.

Запуск проверки пределов и совместимости каталога:

```sh
node tests/country-maps.test.js
```

При следующем релизе включите изменённые `city-roads.js` и `city-map-store.js`. Звуковые компоненты и база камер этим изменением не затрагиваются.
