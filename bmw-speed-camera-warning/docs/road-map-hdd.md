# Дорожные карты на HDD — SpeedCAM 0.9.99

Файлы SCROAD01 переносятся из `dataDir/city-maps` в отдельный каталог
`/var/opt/hdshare/speedcam-city-maps-<uid приложения>`.
`installed.json` и каталог остаются в прежней папке приложения; поле `_storage`
указывает размещение каждого файла. База камер, настройки и звук не переносятся.

Используется только уже смонтированный в `/var/opt/hdshare` доступный для записи
блочный раздел на другом устройстве относительно dataDir. Нет форматирования,
изменения разделов, подключения дисков или изменения прав системных каталогов.
Каталог приложения создаётся с правами 0700. Если пользователь приложения не
может его создать/записать, используется прежнее хранилище. Реальные права на
конкретной прошивке требуют проверки на MGU; тест на ПК этого не подтверждает.

При первом обнаружении HDD приложение показывает диалог до копирования. «Продолжить» запускает перенос, «Позже» откладывает его до следующего открытия приложения после перезапуска. Решение о начале сохраняется в `hdd-transfer.json`; прерванный начатый перенос затем продолжается автоматически. После полного переноса появляется отдельный диалог с количеством проверенных карт. Частичная ошибка не объявляется успехом. Итоговое окно сохраняется до подтверждения и не повторяется после закрытия. Пустое хранилище получает сообщение о готовности HDD, без заявления о перенесённых файлах.

Перенос выполняется асинхронно, по одному файлу. Проверяются размер, SHA-256,
формат, индекс, идентификатор и ревизия. Потоковая копия в `.migrating` ограничена
128 КиБ на блок. После fsync, повторной проверки и переименования на HDD запись
реестра сохраняется атомарно. Исходный файл удаляется только после этого.
Повторный запуск использует оставшуюся проверенную копию, если процесс оборвался
между копированием и фиксацией реестра. Неполный файл не становится установленной
картой. Ошибка копирования или фиксации сохраняет исходник.

Перед записью свободное место проверяется `df -Pk`; дополнительно оставляется
64 МиБ. Ограничение отдельного файла остаётся 64 МиБ. Лимит набора карт на HDD увеличен до 4 ГиБ; для локального хранилища сохранены 128 МиБ. Лимиты считаются отдельно, а свободное место проверяется перед каждой записью.
При отсутствии HDD, прав записи, сведений о свободном месте или места перенос
не завершается; новые загрузки могут использовать прежнюю папку. Если HDD
исчезает прямо во время загрузки, операция завершается ошибкой без замены старой
карты; следующая попытка может загрузить её локально.

Диск повторно проверяется каждые 30 секунд, в том числе без GPS. Обнаружение
отключения при отображении кэшируется не более секунды; перед изменением файлов
и удалением исходника проверка принудительно обновляется. При исчезновении HDD
после завершённого переноса дорожные карты на нём недоступны до подключения
или повторной загрузки во внутреннюю память. Записи в списке не теряются;
удаление недоступной HDD-карты не объявляется успешным. Локальные карты и
независимый контроль камер продолжают работать. Автоматически скачивать дубликаты
в фоне приложение не будет.

В меню карт отображается текущий лимит HDD либо внутреннего хранилища. Диалоги переведены на русский и английский; доступны касанием и джойстиком, в GPU и PNG. Возврат к старому приложению
не выполняет обратный перенос; старая версия не знает расположения HDD-карт.

Проверки: `tests/city-map-hdd.test.js`, `tests/city-map-hdd-package.test.js`,
прежние тесты установки, обновления, удаления, выбора пересекающихся регионов,
группировки и управления картами. Используется Node.js 8.17.0. Проверка на
физическом HDD MGU и после сна автомобиля не выполнялась.
