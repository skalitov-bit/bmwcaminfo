# Проверочная сборка GitHub Actions

Сценарий `Build and verify SpeedCAM` собирает текущие исходники из checkout. Код синхронизирован с точным архивом исходников релиза 0.9.92. Название исторического файла workflow сохранено, но публикации из него больше нет.

## Запуск

GitHub → Actions → Build and verify SpeedCAM → Run workflow. Также запускается при изменениях исходников или workflow в main и pull request. Старое еженедельное расписание удалено.

- Задача build: тесты CI, синтаксис Node.js 8.17.0, регрессии, сборка MGU/TGZ, каталог магазина, запуск упакованного приложения, GPU/PNG и управление.
- Задача separate-maps: получает актуальный публичный каталог из speedcam-db, проверяет SHA-256 обеих региональных карт, чтение областей, установку, обновление, отклонение повреждений и удаление без изменения камер.
- Результаты доступны только в Actions Artifacts (14 дней). CHECKS.json содержит итоги и отличия содержимого пакета от 0.9.92. Архивы gzip могут иметь разные временные метки, поэтому сравнивается содержимое файлов.

## Входные ресурсы

`tools/ci-inputs.json` фиксирует URL, размер и SHA-256 опубликованных исходников 0.9.92, бинарного аудиокомпонента 0.1.49 и эталонного TGZ. Из архива извлекаются только перечисленные ресурсы: два бинарных файла камер, существующая геометрия совместимости, иконка и лицензия шрифта. Код и app.json из архива не перезаписываются. Код собирается из Git.

`tools/build-inputs.json` фиксирует базовый runtime и инструменты сборки. Кэш проверяется по контрольным суммам; повреждённый вход завершает задачу ошибкой. Версии приложения и сервиса читаются из исходных манифестов и проверяются против lock, без подстановки 0.9.1.

Аудиокомпонент 0.1.49 используется без пересинтеза и изменения файлов. Для изменения сервиса требуется отдельная проверенная сборка и обновление lock. Для новых релизов обновляйте lock после проверки ресурсов и сохраняйте соответствующие исходники.

Дорожные пакеты SCROAD01 Москвы/области и Петербурга/области остаются в speedcam-db. Они не включаются в MGU/TGZ и не требуют регионального PBF при сборке приложения. Этот CI не строит и не публикует карты, базу камер или голоса.

## Сохранность выпуска

У workflow только `contents: read`; нет команд публикации, токенов записи или изменения тега/Latest/каталога Store. Релиз 0.9.92 и его файлы не меняются. Проверка в Actions не подтверждает работу на физическом MGU.
